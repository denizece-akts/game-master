# GameMaster

GameMaster is a RAG-based chatbot for querying game data and reviews.

## Project Structure

```
.
├── main.py                 # Streamlit application entry point
├── config.json             # Main configuration
├── pyproject.toml          # Project dependencies and settings
├── README.md               # Project documentation
├── gamemaster/
│   ├── cli.py              # CLI entry point
│   ├── config/             # Configuration logic
│   ├── core/               # Core RAG engine logic
│   ├── services/           # External services (LLM, Embeddings)
│   ├── data/               # Data loading and processing
│   ├── evaluation/         # Evaluation scripts
│   ├── utils/              # Utility functions
│   └── resources/          # Static resources (Q&A Datasets)
```

## Setup

1. Install `uv` if you haven't already.
2. Run `uv sync` to install dependencies.
3. Configure `config.json` in the root directory if needed.

## Usage

### Run the Chatbot (Streamlit)

```bash
uv run streamlit run main.py
```
*Use the "Enable Conversation History" checkbox in the sidebar to toggle history.*

### Run the CLI

**Interactive Mode (with optional history):**
```bash
uv run python -m gamemaster.cli --history
```
*Type `reset` to clear history during the session.*

**Single Query Mode:**
```bash
uv run python -m gamemaster.cli "Which game features dwarves?"
```

### Run Evaluation

To run the full evaluation pipeline (Retrieval + Quality Check):
```bash
uv run python -m gamemaster.evaluation.run
```
*To run only the retrieval step (faster, no OpenAI costs):*
```bash
uv run python -m gamemaster.evaluation.retrieval
```

## Configuration

The `config.json` file controls behavior:
- **`max_history_turns`**: Number of conversational turns to keep in context (default: 3).
- **`qa_set_filename`**: Dataset to use for evaluation (e.g., `qa_v3.jsonl`).
